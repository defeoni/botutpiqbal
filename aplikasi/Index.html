PREFERENSI & DATA

Pengaturan Proyek

Kelola sumber material dan data operasional proyek.

Ruang kerja Material

Simulasi review, revisi, lampiran, dan final terpisah dari data server. Simulasi hanya dalam memori; hilang saat halaman dimuat ulang. File hanya dicatat namanya.

Reset Administrasi Proyek di perangkat

Hanya draf modul proyek perangkat ini. Arsip Google dan administrasi HO tetap dipertahankan.

Reset data Proyek di server

Arsipkan permintaan, persetujuan, tugas, keuangan, arsip proyek, catatan personel lama, dan absensi. Master, file Drive, Memo, RPB, RPD, dan akses login dipertahankan. Data tetap disimpan sebagai arsip audit.

SISTEM & DOKUMEN

Pengaturan Head Office

Penomoran, arsip Memo, dan koneksi Telegram.

Beberapa tindakan memerlukan kode konfirmasi. Bagikan URL aplikasi hanya kepada orang yang berhak mengaksesnya.

Hapus Semua Riwayat Memo

Tindakan ini menghapus seluruh riwayat memo dan memindahkan file memo terkait ke Sampah Google Drive.

Reset Counter Penomoran

Reset hanya berlaku untuk periode bulan berjalan. Gunakan dengan hati-hati agar tidak menimbulkan nomor dokumen duplikat.

Telegram tersambung dan dipelihara otomatis setelah konfigurasi bot tersedia. Tidak perlu menekan tombol hubungkan.

Reset Memo

Tindakan ini memindahkan file yang tercatat pada riwayat Memo ke Sampah Google Drive, mengosongkan riwayat Memo, dan mereset counter Memo saja. RPB, RPD, Nota/Keuangan, Material, template, Manpower, dan modul lain tidak ikut dihapus.

Lampiran dan Output

Foto KTP diisi langsung pada baris setiap personel. Setiap lampiran akan diberi nama sesuai kolom “Nama untuk KTP” dan masuk ke sheet kedua. Maksimal 30 foto per memo.

Sedang memproses dokumen. Jangan tutup halaman ini.

Periksa Memo Sebelum Membuat Arsip

Nomor belum digunakan. Counter baru bertambah setelah arsip berhasil dibuat.
