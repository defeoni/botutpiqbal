# Arsip referensi lama

Folder ini mempertahankan salinan lama tanpa menimpa atau menghapus isinya.

- `kode-lama/versi-awal/`: file Code.gs/Index/Client/Styles/manifest dan pratinjau yang dahulu berada di root. Tidak masuk build aktif.
- `kode-lama/versi-modular/`: Client.html lama yang dahulu berada di legacy/.
- `panduan-lama/`: README memo dan checkpoint lama. Isinya riwayat; keputusan terbaru berada di panduan/STATUS-BREAK.md dan panduan/MULAI-DI-SINI.md.

Jangan menambahkan salinan kode arsip ke Apps Script; fungsi duplikat dapat bertabrakan. Sumber aktif hanya di aplikasi/ sesuai daftar alat/buat-sumber-clasp.js.
